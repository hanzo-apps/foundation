# Hanzo Foundation

Official website for the Hanzo Foundation - building frontier AI and foundational models.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Deployment

This site is deployed to GitHub Pages via GitHub Actions on push to main.
